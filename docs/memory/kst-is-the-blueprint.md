Founder ruling 2026-07-30: **KST Accountants is a minor account by revenue but serves a greater purpose. It is the lab rat and the blueprint** for the next accounting client and for the next non-dental lead-gen client.

**Why it matters:** it changes the standard for work done there. Anything built for KST should be built to be cloned, not just to work once. A hand-built one-off that functions is a failure against this brief even if the client is happy.

**How to apply:**
- Prefer portable artefacts over bespoke ones: GHL snapshots, documented record sets, parameterised specs.
- **As of 2026-07-30 the KST GHL location has an empty `snapshotId`, meaning it was built entirely by hand and none of it is currently portable.** Capturing it as a snapshot is outstanding work: pipeline, the two OCT workflows, Website Lead Notifications, custom fields, chat agent config, nurture sequence once built.
- When choosing between a quick fix and a reusable pattern at KST, the reusable pattern wins even at higher cost.
- Non-dental matters: DentalMastery patterns assume a dental vertical. KST is the proof that the stack works without that assumption.
